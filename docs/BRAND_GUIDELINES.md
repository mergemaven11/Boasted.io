# Boasted Brand Guidelines

![Boasted wordmark](../frontend/public/boasted-wordmark.png)

## Brand name

**Boasted** is the customer-facing product and brand name.

Primary web domain: **boasted.io**

Use `Boasted` in normal prose and product copy. Use the lowercase custom wordmark artwork when displaying the visual brand.

## Primary wordmark

The canonical Boasted wordmark asset is:

```text
frontend/public/boasted-wordmark.png
```

The wordmark uses the existing Boasted/legacy BragStack visual system: deep navy with electric-blue accents. The upward ribbon details communicate confidence, proof, progress, and momentum without changing the established brand palette.

### Preferred usage

Use the wordmark for:

- Marketing-site navigation and branded hero areas
- Customer-facing documentation and Help Center headers
- Brand presentations and product documentation
- Social/profile headers where a horizontal logo is appropriate
- Launch and marketing graphics

Keep enough clear space around the wordmark for the blue accents to remain readable. Do not stretch, skew, rotate, crop through the letters, add unrelated colors, or place effects over the artwork that reduce legibility.

## Existing brand mark

The existing square Boasted brand mark remains valid and should **not** be deleted. Continue using it when a compact icon is required, including:

- Favicons
- App icons
- Small avatars
- Square UI locations
- Mobile locations where the full wordmark would be too wide

The wordmark and square brand mark are complementary assets, not replacements for each other in every context.

## Colors

The rebrand intentionally preserves the established theme colors. Do not introduce a new palette simply because the name changed.

Current primary brand direction:

- Deep navy / near-black surfaces
- Electric blue highlights
- Existing blue-to-purple accents used by the product UI
- White and cool-gray typography for contrast

The generated wordmark itself should be treated as a fixed artwork asset. Avoid recoloring individual letters or the blue ribbon accents unless a future formal logo system defines approved variants.

## Product usage

The full wordmark is now the preferred visual treatment in the marketing navigation and customer-facing Help Center. Plain-text `Boasted` should remain in semantic HTML, accessibility labels, metadata, SEO copy, emails, legal/product prose, and places where an image logo would reduce clarity.

Internal compatibility identifiers such as legacy component names, token keys, environment-variable names, and infrastructure names do not need to be renamed solely for visual branding.

## Naming rule

Customer-facing references should use:

```text
Boasted
boasted.io
```

Do not reintroduce `BragStack` as a customer-facing product name. If `BragStack LLC` remains the company's current legal entity name, legal references may continue to use that exact legal name until the entity itself is formally changed.
