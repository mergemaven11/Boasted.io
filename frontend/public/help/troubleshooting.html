BRAGSTACK TECHNICAL SUPPORT

Something went wrong? Start here.

This guide covers the most common BragStack problems and the safest recommended fixes. Try the steps in order. If the issue continues, contact support@usebragstack.com and include the details listed at the bottom of this page.

Sign-inBillingInterview & AishaApp problems

Before anything else

FAST CHECK

Try these four steps first

  1. Refresh the page once.
  2. Confirm your internet connection is stable.
  3. Sign out and sign back in.
  4. Try a private/incognito window with extensions temporarily disabled.
DO NOT SEND

Protect sensitive information

Never email passwords, API keys, access tokens, card numbers, security codes, confidential workplace evidence, restricted source code, or customer data. Screenshots should be cropped or redacted when necessary.

Sign-in, Google, GitHub & account access

Google or GitHub sign-in returns you to the login page

  1. Return to the BragStack login page and start the sign-in again.
  2. Use the same provider and account you originally used.
  3. Allow pop-ups and redirects for usebragstack.com for the sign-in attempt.
  4. Disable strict privacy/ad-blocking extensions temporarily.
  5. Try an incognito/private window.

If you appear logged in only after typing the site URL again, report that behavior with the browser name and approximate time.

OAuth window closes, hangs, or shows an error

  1. Do not repeatedly refresh the provider callback page.
  2. Close the failed tab or popup.
  3. Return to BragStack and start sign-in again.
  4. Verify browser cookies are allowed for the session.
  5. Try another supported browser if the problem repeats.

Email/password sign-in fails

  1. Confirm the email address is typed correctly.
  2. Check Caps Lock and password-manager autofill.
  3. Use the password recovery flow if available.
  4. If you normally sign in with Google or GitHub, use that provider instead of creating a second login path.

You are signed in, but the wrong account appears

  1. Sign out of BragStack.
  2. Check which Google/GitHub account is active in the browser.
  3. Open BragStack again and deliberately choose the correct identity.
  4. Do not create duplicate accounts to work around the issue.

Billing, Stripe, coupons & Pro access

Payment succeeded but Pro is still locked

  1. Wait a few seconds for account entitlement to update.
  2. Refresh the app once.
  3. Sign out and back in.
  4. Confirm checkout used the same BragStack account you are currently signed into.
  5. If it remains locked, send support the receipt time and your BragStack account email.

Coupon or promo code does not apply

  1. Confirm the code is entered exactly as provided.
  2. Check that the promotion has not expired.
  3. Check whether the code is limited to new customers, one use, or a specific redemption count.
  4. Restart checkout from BragStack instead of reusing an old checkout tab.

Checkout page does not open or returns an error

  1. Allow redirects/pop-ups for the checkout attempt.
  2. Disable blocking extensions temporarily.
  3. Start a fresh checkout from the BragStack pricing page.
  4. Do not reuse a stale checkout session from browser history.

Do not send payment secrets

Support does not need your full card number, CVC, bank credentials, or password. A receipt timestamp, checkout error message, and BragStack account email are enough to begin investigating.

Practice Interview, microphone, speech & Aisha

Aisha does not appear

  1. Refresh the interview page once.
  2. Confirm the session finished loading before interacting.
  3. Start a new practice session if the current session appears incomplete.
  4. Try an incognito/private window if browser extensions may be blocking media or scripts.
  5. Report whether you saw a blank avatar area, loading state, or error message.

Aisha appears but does not speak

  1. Confirm the browser tab is not muted.
  2. Raise system and browser volume.
  3. Allow audio playback for usebragstack.com.
  4. Interact with the page once if the browser requires a user gesture before audio playback.
  5. Reload the session and try again.

Microphone does not start listening

  1. Allow microphone permission for usebragstack.com.
  2. Close Zoom, Teams, Discord, OBS, voice recorders, or other apps using the microphone.
  3. Check the browser is using the intended microphone device.
  4. Reload the interview page after changing permission.
  5. Use text answering temporarily if voice capture is unavailable.

Timer starts too early, too late, or while Aisha is speaking

  1. Stop the current session and start a fresh one.
  2. Do not click multiple start/next controls in quick succession.
  3. Report the exact sequence: question begins, speech ends, timer begins, microphone begins.
  4. Include a screen recording if possible, with private information removed.

Mouth animation or avatar movement looks frozen

  1. Reload the page.
  2. Confirm hardware acceleration is enabled in the browser where possible.
  3. Close high-CPU/GPU tabs or apps.
  4. Try another modern browser.
  5. Report whether audio continued while animation stopped.

Speech recognition is inaccurate

  1. Move closer to the microphone and reduce background noise.
  2. Select the correct input device.
  3. Speak naturally but avoid talking over the prompt audio.
  4. Use text editing before submitting if available.
  5. Include the browser/device when reporting repeated recognition errors.

Resume Builder & Career Intelligence

Resume generation appears stuck

  1. Wait briefly before retrying.
  2. Avoid clicking Generate repeatedly.
  3. Refresh once if no result or error appears.
  4. Shorten extremely large pasted job descriptions and try again.
  5. Report the approximate time and whether any partial result appeared.

Generated resume content is missing or looks wrong

  1. Confirm the relevant accomplishments or Impact Receipts are saved.
  2. Check the target role/job description is the intended one.
  3. Regenerate once after correcting inputs.
  4. Always review and edit final output before using it.
  5. Do not add experience you did not actually have just to fill a detected gap.

Career Intelligence feedback feels unrelated

  1. Confirm the target job, competency, or interview type is correct.
  2. Provide more specific evidence about what you personally did and what changed.
  3. Remove irrelevant proof from the session where possible.
  4. Try again with a clearer job description or accomplishment.

Export/download does not work

  1. Allow downloads for usebragstack.com.
  2. Check the browser download tray/folder.
  3. Try again after refreshing the page.
  4. Try another browser if the file never begins downloading.

Accomplishments, Impact Receipts & public proof

An accomplishment will not save or update

  1. Wait for any current save request to finish.
  2. Refresh once, then retry the edit.
  3. Reduce unusually large pasted text or attachments.
  4. Copy important unsaved text somewhere safe before reloading.
  5. Report the page name and exact error message.

Public profile or shared proof looks outdated

  1. Confirm the item is intentionally marked for public visibility.
  2. Refresh the public page without using an old browser tab.
  3. Check you are viewing the correct public profile/slug.
  4. If stale content remains, report the public page address and what should have changed.

Evidence upload fails

  1. Confirm the file is not unusually large and is a supported type.
  2. Rename files with unusual characters if necessary.
  3. Retry on a stable connection.
  4. Do not upload restricted employer/client material merely to test the feature.

Duplicate or unexpected entries appear

  1. Do not repeatedly click Save while the first request is processing.
  2. Refresh the list to confirm whether the duplicate is real.
  3. Delete only the confirmed duplicate.
  4. Report what action created the duplicate so support can trace it.

Pages that will not load, save, or update

Blank page or endless loading

  1. Refresh once.
  2. Open a new tab and navigate directly to usebragstack.com.
  3. Try private/incognito mode.
  4. Disable extensions that alter scripts, cookies, or network requests.
  5. Try another modern browser.

Buttons do nothing

  1. Wait for any loading indicator to finish.
  2. Click once, not repeatedly.
  3. Refresh the page if the action never begins.
  4. Try the same action in a private window.
  5. Report the button label and page.

Changes disappear after refresh

  1. Confirm a save-success message appeared before leaving the page.
  2. Retry the save once.
  3. Sign out and back in if the session may have expired.
  4. Copy important text before further troubleshooting.
  5. Report which fields failed to persist.

Unexpected error message

  1. Copy the exact message or take a screenshot.
  2. Note the page, approximate time, and action you performed immediately before it.
  3. Refresh once and retry only once.
  4. If the same error repeats, stop retrying and contact support.

Browser, cache, cookies & permissions

Recommended browser checks

  • Use a current version of Chrome, Edge, Firefox, or Safari.
  • Allow required cookies for sign-in sessions.
  • Allow microphone permission for voice interview features.
  • Allow redirects/pop-ups when needed for OAuth or checkout.
  • Do not clear all browser data as the first troubleshooting step; try a private window first.

When clearing site data makes sense

Only clear BragStack site data after simpler steps fail. Clearing cookies/session data signs you out and may remove locally cached state. Make sure any unsaved text has been copied somewhere safe first.

Security & suspicious activity

Unexpected sign-in or account activity

  1. Sign out of BragStack.
  2. Secure the Google, GitHub, or email account used to sign in.
  3. Change affected credentials with the identity provider if appropriate.
  4. Review active sessions or connected apps at that provider.
  5. Contact support with the approximate time and what looked unusual.

Possible vulnerability

Send a clear description, affected page/feature, reproduction steps, browser/device, and impact. Do not exploit the issue further than needed to demonstrate it. Do not access data that is not yours. Do not include passwords, tokens, or confidential evidence in the report.

What to include in a support request

Useful details

  • Your BragStack account email.
  • Page or feature name.
  • Approximate date and time of the problem.
  • Browser and browser version.
  • Device and operating system.
  • Exact error message.
  • What you clicked immediately before the issue.
  • Whether the problem repeats in a private/incognito window.
  • A redacted screenshot or short screen recording when helpful.

Keep private information private

Never include your password, API keys, access tokens, full payment-card data, employer secrets, confidential documents, customer data, or evidence you are not authorized to share. Describe sensitive material instead of attaching it.

Still stuck? Stop repeatedly retrying an action if it could create duplicate entries, duplicate charges, or conflicting saves. Capture the error details and contact support instead.

Contact BragStack Support

Email support@usebragstack.com. Include the feature, approximate time, browser/device, exact error, and the steps that led to it. For security concerns, use the subject “BragStack security report.”

BragStack will never need your password, access token, full card number, or confidential workplace evidence to begin troubleshooting.
