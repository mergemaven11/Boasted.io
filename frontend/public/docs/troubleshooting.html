Something went wrong? Start here.

This is the dedicated product-issues page. Try the recommended fixes first. If the problem continues, contact support@usebragstack.com. Security vulnerabilities, suspected compromise, or data-exposure concerns should go to security@usebragstack.com.

Try these first

FAST CHECK

Four safe first steps

  1. Refresh the page once.
  2. Confirm your internet connection is stable.
  3. Sign out and sign back in.
  4. Try a private/incognito window with extensions temporarily disabled.
DO NOT SEND

Protect sensitive information

Never email passwords, API keys, access tokens, card numbers, security codes, confidential workplace evidence, restricted source code, or customer data. Redact screenshots when necessary.

Sign-in & account access

Google or GitHub sign-in loops back

  1. Return to the BragStack login page and start sign-in again.
  2. Use the same provider and account you originally registered with.
  3. Allow pop-ups and redirects for usebragstack.com.
  4. Temporarily disable strict ad/privacy blockers.
  5. Try a private window.

OAuth popup closes, hangs, or errors

  1. Do not keep refreshing the provider callback page.
  2. Close the failed tab or popup.
  3. Return to BragStack and restart sign-in.
  4. Confirm cookies are allowed for the session.
  5. Try another modern browser.

Wrong account appears

  1. Sign out of BragStack.
  2. Check which Google or GitHub account is active in the browser.
  3. Sign back in and deliberately choose the correct account.
  4. Avoid creating duplicate accounts as a workaround.

Email/password sign-in fails

  1. Verify the email address and Caps Lock.
  2. Check password-manager autofill.
  3. Use password recovery if available.
  4. If you normally use Google or GitHub, use that same provider.

Billing, Stripe, coupons & Pro

Payment succeeded but Pro is locked

  1. Wait a few seconds.
  2. Refresh once.
  3. Sign out and back in.
  4. Confirm checkout used the same BragStack account.
  5. If still locked, send support the receipt time and account email.

Coupon does not apply

  1. Enter the code exactly as provided.
  2. Check expiration date and redemption limits.
  3. Check whether it is new-customer or one-use only.
  4. Start a fresh checkout instead of reopening an old Stripe tab.

Checkout will not open

  1. Allow redirects/pop-ups.
  2. Temporarily disable blocking extensions.
  3. Restart checkout from BragStack.
  4. Do not reuse a stale checkout session from browser history.

What support needs

Send the BragStack account email, approximate checkout time, and exact error message. Do not send full card numbers, CVCs, bank credentials, or passwords.

Practice Interview, microphone & Aisha

Aisha does not appear

  1. Refresh once.
  2. Wait for the interview session to finish loading.
  3. Start a new practice session if the current one is incomplete.
  4. Try a private window if extensions may be blocking media or scripts.
  5. Report whether the avatar area was blank, loading, or errored.

Aisha appears but does not speak

  1. Confirm the tab is not muted.
  2. Raise system/browser volume.
  3. Allow audio playback for usebragstack.com.
  4. Interact with the page once if the browser requires a user gesture.
  5. Reload the session.

Microphone does not listen

  1. Allow microphone permission for usebragstack.com.
  2. Close Zoom, Teams, Discord, OBS, or other apps using the mic.
  3. Choose the intended microphone device.
  4. Reload after changing permissions.
  5. Use text answers temporarily if voice capture is unavailable.

Timer or listening sequence is wrong

  1. Start a fresh session.
  2. Do not press start/next controls repeatedly.
  3. Report the exact order: Aisha starts speaking → Aisha finishes → timer starts → microphone starts.
  4. Include a screen recording if possible, with private data removed.

Mouth or avatar animation freezes

  1. Reload the page.
  2. Enable hardware acceleration where supported.
  3. Close high-CPU/GPU tabs or apps.
  4. Try another modern browser.
  5. Report whether audio continued while animation stopped.

Speech recognition is inaccurate

  1. Reduce background noise.
  2. Move closer to the mic.
  3. Select the correct input device.
  4. Avoid speaking over Aisha.
  5. Include browser and device details when reporting repeated errors.

Resume Builder & Career Intelligence

Resume generation is stuck

  1. Wait briefly before retrying.
  2. Do not click Generate repeatedly.
  3. Refresh once if no result or error appears.
  4. Shorten extremely large pasted job descriptions.
  5. Report the approximate time and whether a partial result appeared.

Generated content is missing or wrong

  1. Confirm the relevant accomplishments/Impact Receipts are saved.
  2. Check the target role and job description.
  3. Regenerate once after correcting inputs.
  4. Review final output before using it.
  5. Do not invent experience to fill an evidence gap.

Career Intelligence feedback feels unrelated

  1. Confirm the target role, competency, or interview type.
  2. Add more specific evidence about what you personally did.
  3. Remove irrelevant proof where possible.
  4. Try again with a clearer job description or accomplishment.

Export or download fails

  1. Allow downloads for usebragstack.com.
  2. Check the browser download tray/folder.
  3. Refresh and try once more.
  4. Try another browser if the download never begins.

Accomplishments, Impact Receipts & public proof

An accomplishment will not save

  1. Wait for any current save to finish.
  2. Copy unsaved text somewhere safe.
  3. Refresh once and retry.
  4. Reduce unusually large pasted text or attachments.
  5. Report the exact error.

Public profile looks outdated

  1. Confirm the item is intentionally public.
  2. Refresh the public page in a new tab.
  3. Check you are viewing the correct profile/slug.
  4. Report the public page address and what should have changed.

Evidence upload fails

  1. Check file size and type.
  2. Rename files with unusual characters.
  3. Retry on a stable connection.
  4. Never upload restricted employer/client material just to test the feature.

Duplicate entries appear

  1. Do not click Save repeatedly while a request is processing.
  2. Refresh the list to confirm the duplicate.
  3. Delete only the confirmed duplicate.
  4. Report the exact action that created it.

Pages that will not load, save, or update

Blank page or endless loading

  1. Refresh once.
  2. Open a new tab and go directly to usebragstack.com.
  3. Try private/incognito mode.
  4. Disable extensions that modify scripts, cookies, or requests.
  5. Try another modern browser.

Buttons do nothing

  1. Wait for any loading indicator to finish.
  2. Click once, not repeatedly.
  3. Refresh if the action never begins.
  4. Try the same action in a private window.
  5. Report the button label and page.

Changes disappear after refresh

  1. Confirm a save-success message appeared.
  2. Copy important text before troubleshooting further.
  3. Retry the save once.
  4. Sign out and back in if the session may have expired.
  5. Report which fields failed to persist.

Unexpected error message

  1. Copy the exact message or take a screenshot.
  2. Note the page and approximate time.
  3. Record the action performed immediately before the error.
  4. Refresh once, then retry only once.

Browser, cache, cookies & permissions

Site behaves differently in another browser

Try a current version of Chrome, Edge, Firefox, or Safari. If the issue only happens in one browser, report the browser name/version and whether extensions are enabled.

Permissions were denied

Open the browser's site settings for usebragstack.com, re-enable the required permission such as microphone or downloads, then reload the page.

Clearing site data

Use this only after simpler fixes. Clearing cookies/site data can sign you out. Save any unsaved work first, then clear site data for usebragstack.com only and sign back in.

Extensions may be interfering

Ad blockers, script blockers, privacy extensions, password managers, and security software can affect OAuth, audio, downloads, or requests. Test in a private window with extensions disabled.

Security issue? If you suspect account compromise, data exposure, or a vulnerability, do not use general support. Email security@usebragstack.com. Do not include passwords, access tokens, or confidential evidence.

Still not fixed?

Email support@usebragstack.com with: the page/feature, what you expected, what happened, exact error text, approximate time, browser/device, and the troubleshooting steps you already tried.

For security vulnerabilities, suspected compromise, or privacy/data-exposure incidents, email security@usebragstack.com.
