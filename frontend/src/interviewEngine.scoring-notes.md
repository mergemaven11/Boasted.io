# BragStack Career Intelligence scoring calibration

The practice interviewer uses behaviorally anchored evidence gates rather than rewarding superficial answer form.

- Relevance must prove the competency being tested.
- Structure requires recognizable situation/context, personal action, and result.
- Ownership requires an actual first-person action; simply saying “I” is not enough.
- Specificity rewards concrete details and causal evidence, not word count alone.
- Impact requires an outcome and rewards truthful scale when available; metrics are never mandatory.
- Communication measures how clearly the answer organizes job-related evidence. Low filler count alone cannot create a strong score.
- Weak answers are capped when critical evidence is missing so one inflated dimension cannot hide a poor response.
- Final-session “strongest areas” are only reported when a dimension actually reaches the Strong threshold (70+).

The calibration follows structured-interview principles: standardized scoring, job-related competencies, behavioral evidence, consistent proficiency thresholds, and STAR-style elicitation.
