# Aisha interview sequence acceptance checks

1. Aisha image is visible before speech starts.
2. Intro is split into short sections with ~5 second pauses between sections.
3. First interview question is spoken only after the intro completes and another ~5 second pause.
4. Response timer does not start until the spoken question ends.
5. Microphone/listening auto-starts only after the timer starts and Aisha is no longer speaking.
6. At 0:00, listening stops, a soft chime plays, and Aisha says: “Okay, that’s time. Thank you.”
7. Feedback is evaluated, then a targeted follow-up is selected when available; otherwise the next question advances.
8. Follow-up and subsequent questions are spoken automatically, then the same timer/listening cycle repeats.
9. Aisha mouth movement remains subtle and only appears while speaking.
10. Existing OAuth, marketing, and resume-builder behavior are out of scope and untouched.
